Information for IT and security teams

VoiceWord for IT teams

A member of your team would like to use VoiceWord at work. This page explains what it is, what it does on a PC, and what it connects to, so you can decide whether to allow it.

What VoiceWord is

VoiceWord is a free Windows accessibility and productivity app. It lets people talk to type (speech to text in any app), listen to text (text to speech for highlighted text or a page), and check their writing (spelling and grammar). It runs from the notification area near the clock. It is made in New Zealand by VoiceWord (Carly).

At a glance

Install typePer-user install. No admin rights needed. Installs to %LOCALAPPDATA%\Programs\VoiceWord.
Where it keeps dataSettings, speech and voice files, word lists and logs live in %LOCALAPPDATA%\VoiceWord\data, for that user only.
ProgramVoiceWord.exe (desktop app, Windows 10 1809 or later, x64). Publisher: VoiceWord (Carly).
Two ways to get it1. Microsoft Store (by invitation for now). Store builds are reviewed and signed by Microsoft and update through the Store.
2. Installer from GitHub (coming later, VoiceWord-Setup-….exe). Not code-signed, so Windows SmartScreen shows a warning. Each release lists the installer's SHA-256 so you can check the file.
Cost, account, adsFree. No account or sign-in. No ads. No analytics or tracking.
UninstallSettings > Apps > VoiceWord > Uninstall. The uninstaller can also remove the user's data folder.

What it does on the PC, and why

  • Low-level keyboard and mouse hooks (WH_KEYBOARD_LL, WH_MOUSE_LL). Used only to notice VoiceWord's own shortcut keys and when the user highlights text, so it can show its Read / Check buttons. Keystrokes are not recorded, stored or sent.
  • UI Automation (the Windows accessibility interface). Used to read the highlighted text or the current page aloud, and to tell whether the cursor is in a text box.
  • Clipboard and simulated keystrokes. Dictated text is put into the user's app by pasting. The user's clipboard is saved first and put back afterwards.
  • Microphone. Only while the user is dictating. Speech recognition runs on the PC (Whisper, via faster-whisper). Audio is not saved to disk and not sent anywhere.
  • Camera. Only if the user chooses "Read a printed page". The picture is read with the built-in Windows OCR and is not kept.
  • Optional AI helper. If the user turns it on, VoiceWord downloads Ollama (a separate, signed program) and runs it for that user, listening on 127.0.0.1 only, at below-normal priority. It is used to rewrite or explain text on the PC. It can be removed again from VoiceWord's "Add or remove features" window.

What it connects to

  • Downloads during setup, and when the user adds features: speech, voice and language files from huggingface.co and github.com (GitHub's download servers), and, if chosen, Ollama from github.com and its AI model from registry.ollama.ai. Every download is checked against a SHA-256 before use.
  • Update check (GitHub version only): api.github.com, at most once a day. The user is asked before anything is installed. Store builds are updated by the Store instead.
  • Problem reports: only when the user clicks Send. Technical details only (version, Windows version, memory, error details, VoiceWord's own log with personal details removed), sent to Google Forms (docs.google.com). Never anything the user said, typed or read.
  • Links the user clicks (feedback form, support page, help) open in the web browser.

Nothing the user says, types or reads leaves the PC. There is no telemetry.

If you want to allow it

  • The Microsoft Store version is the simplest to approve: it is reviewed and signed by Microsoft.
  • For the GitHub version, allow %LOCALAPPDATA%\Programs\VoiceWord\VoiceWord.exe (or the installer by its SHA-256 from the release page).
  • If your security software flags keyboard hooks, the reason is above: VoiceWord's shortcut keys and highlight detection.
  • For use without internet after setup: once the speech and voice files are downloaded, dictation, reading aloud and writing checks all work offline.
